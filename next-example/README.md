# Solana swap Next.js example app using Jupiter APIs

Example Next.js app to swap tokens on Solana using Jupiter APIs.

## Create the secrets file

First, create a `.env.local` file in the root directory by copying the template `.env.example`. Then fill it up with the required secrets.

## Installation

Install dependencies:

```
bun i
```

## Execution

Run the script:

```
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
